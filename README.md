# 📘 Журнал — Алгебра и начала анализа — 10 А

Streamlit-приложение для распознавания PDF-журнала (OCR), анализа данных,
построения графиков развития по темам, выявления слабых сторон, генерации
рекомендаций и вопросов для отработки. Экспорт в Excel и печать.

## Возможности

- 📄 Загрузка PDF-журнала и OCR-распознавание (Tesseract, рус+каз+eng)
- 👥 Все ученики в одной таблице, топ‑3 лучших и топ‑3 отстающих
- 📈 График развития по темам для каждого ученика
- 💪 Сильные стороны и 📉 слабые темы
- 🩺 Обработка пропусков «А» (болел) и «С» (уважительная)
- 📝 По 5 вопросов на каждую пропущенную/слабую тему
- ⬇ Экспорт в Excel (журнал + сводка + топ + рекомендации)
- 🖨 Печать через браузер

## Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
